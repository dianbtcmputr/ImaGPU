# ImaGPU
ImaGPU (= Image + GPU): a GPU image-processing playground with user-written GLSL shaders (filled into built-in templates to form a compute shader). Two-stage sizer/pixer pipeline, custom uniforms, boundary modes, live preview, reference images, and .imgpu presets. Built with Python, Tkinter, ttkbootstrap, Pyglet, and Pillow.
